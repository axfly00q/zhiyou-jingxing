# 产品部署和使用手册

## 1. 系统概述

智游景行是一套面向景区导览场景的 AI 数字人系统，包含：

| 模块 | 说明 | 默认地址 |
|---|---|---|
| Web 整合端 | 游客端、后台、大屏的统一入口 | `http://localhost:5173` |
| Orchestrator 后端 | FastAPI 业务编排与 API 服务 | `http://localhost:8010` |
| PostgreSQL | 业务数据存储 | `localhost:5432` |
| Redis | 缓存与会话辅助 | `localhost:6379` |
| Neo4j | 景区知识图谱 | `http://localhost:7474` |
| Dify / ASR / TTS | 大模型、语音识别、语音合成外部能力 | 按 `.env` 配置 |

## 2. 环境准备

## 4. 推荐启动方式：本地演示模式

该方式适合演示和开发：数据库等基础服务用 Docker，后端和 Web 端本地运行。

### 4.1 启动基础服务

```powershell
cd D:\zhiyou-jingxing\deploy
docker compose up -d postgres redis neo4j
```

如需 Dify：

```powershell
cd D:\zhiyou-jingxing\dify
docker compose up -d
docker restart dify-nginx-1
```

### 4.2 启动后端

```powershell
cd D:\zhiyou-jingxing\orchestrator
if (!(Test-Path .venv)) { python -m venv .venv }
.\.venv\Scripts\Activate.ps1
pip install -e .[dev]
python -m uvicorn app.main:app --host 0.0.0.0 --port 8010
```

后端 API 文档：

```text
http://localhost:8010/docs
```

### 4.3 启动 Web 端

新开一个 PowerShell：

```powershell
cd D:\zhiyou-jingxing\frontend-web
npm install
npm run dev
```

访问：

```text
http://localhost:5173
```

## 5. Web 端打包与部署

### 5.1 生产打包

```powershell
cd D:\zhiyou-jingxing\frontend-web
npm install
npm run build
```

产物目录：

```text
D:\zhiyou-jingxing\frontend-web\dist
```

当前已生成压缩包：

```text
D:\zhiyou-jingxing\deliverables\frontend-web-dist.zip
```

### 5.2 Nginx 部署要点

将 `dist` 内容放入 Nginx 静态目录，并配置：

```nginx
location / {
  try_files $uri $uri/ /index.html;
}

location /api/ {
  proxy_pass http://127.0.0.1:8010;
}

location /static/ {
  proxy_pass http://127.0.0.1:8010;
}
```

如果部署在 Docker Compose 中，`frontend-web/nginx.conf` 已使用 `http://orchestrator:8010` 作为后端代理地址。

## 7. 基本使用流程

1. 打开 `http://localhost:5173`。
2. 在游客端选择游览偏好，生成个性化路线。
3. 进入对话页，输入文字或语音问题。
4. 数字人返回讲解内容，并播放语音、表情和动作。
5. 进入后台页面，查看知识库、数字人配置和服务建议。
6. 进入数据大屏，查看问答热度、满意度趋势和景点热力。

## 8. 常见问题

| 问题 | 处理 |
|---|---|
| 5173 打不开 | 检查 `npm run dev` 或 Nginx 是否启动 |
| 前端能打开但接口失败 | 检查 Orchestrator 是否在 8010 端口运行 |
| `/api` 404 或 502 | 检查 Nginx 反向代理地址 |
| 数字人模型不显示 | 检查 VRM 模型是否已上传，浏览器是否支持 WebGL |
| 没有语音 | 检查 TTS 服务和 `.env` 配置，系统可降级为文本回答 |
| Dify 调用失败 | 检查 `DIFY_BASE_URL`、`DIFY_API_KEY` 和 Dify 容器状态 |
