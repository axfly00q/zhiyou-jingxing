# 产品源代码及可执行文件说明

## 1. 交付范围

项目名称：智游景行 - 景区导览 AI 数字人系统

本交付物包含产品源代码、Web 端生产构建产物，以及关键运行入口说明。当前仓库根目录即为完整源码目录：

```text
D:\zhiyou-jingxing
```

重点源码目录如下：

| 目录 | 说明 |
|---|---|
| `frontend-web/` | Web 整合端，包含游客端、管理后台、数据大屏路由 |
| `orchestrator/` | FastAPI 后端编排服务，负责对话、路线、后台、统计等 API |
| `miniprogram-tourist/` | 微信小程序游客端 |
| `deploy/` | Docker Compose、环境变量模板 |
| `docs/` | 设计、部署、验收、评测等文档 |

## 2. Web 端可执行产物

已生成的 Web 端生产构建目录：

```text
D:\zhiyou-jingxing\frontend-web\dist
```

已压缩的 Web 端静态交付包：

```text
D:\zhiyou-jingxing\deliverables\frontend-web-dist.zip
```

该 zip 解压后可部署到 Nginx、Apache、对象存储静态网站或任意静态 Web 服务器。由于前端通过 `/api` 和 `/static` 访问后端，生产部署时需要把这两个路径反向代理到 Orchestrator 后端服务。

## 3. Web 端打包命令

在 PowerShell 中执行：

```powershell
cd D:\zhiyou-jingxing\frontend-web
npm install
npm run build
```

构建成功后产物输出到：

```text
frontend-web\dist
```

本次验证结果：`npm run build` 已通过，Vite 成功生成 `index.html`、CSS 和 JS 静态资源。构建过程中出现 chunk 体积提示，这是性能优化建议，不影响正常打包和部署。

## 4. 本地预览命令

方式一：Vite 预览生产包。

```powershell
cd D:\zhiyou-jingxing\frontend-web
npm run preview
```

访问：

```text
http://localhost:5173
```

方式二：用任意静态服务器托管 `dist`。注意不能直接双击 `index.html` 作为正式验收方式，因为路由回退和 `/api` 代理需要 Web 服务器支持。

## 5. Docker 镜像方式

`frontend-web` 已提供多阶段构建 Dockerfile。构建镜像：

```powershell
cd D:\zhiyou-jingxing\frontend-web
docker build -t zhiyou-jingxing-frontend-web:latest .
```

如果与后端 Orchestrator 在同一个 Docker 网络中运行，并且后端服务名为 `orchestrator`，可直接使用镜像内置的 Nginx 配置代理 API：

```powershell
docker run --rm -p 5173:80 --network zhiyou-jingxing_default zhiyou-jingxing-frontend-web:latest
```

访问：

```text
http://localhost:5173
```
